## The joke

> Monday morning, my alarm clock quit its job — it said waking me up five days a week was inhumane, so now we just lie there, unemployed together.

## How it works

`main.py` (Python 3.13, stdlib only, no network) writes that single joke
— 144 characters — to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`). It is fully deterministic: every run
writes the exact same bytes.

## Run

```sh
python3 main.py
```
